# Number Guessing Game

Number Guessing Game is a console application where the player tries to guess a randomly selected number between 1 and 100 within a limited number of attempts.

## What This Project Shows

- Accepts console input for difficulty selection and number guesses.
- Uses a randomly generated number for each game round.
- Provides feedback on guesses to indicate whether they are too high, too low, or close.
- Tracks remaining attempts and ends the game with a win or loss message.
- Loads ASCII art from a local module to display the game title.

## How to Run

### Prerequisites

* Python 3.8 or newer
* Visual Studio Code (optional)

### Steps

1. Clone the repository.
2. Open the `Day 11 - Day 20/Day 12 - Number Guessing Game` folder.
3. Open a terminal in the project folder.
4. Run the application.

### Run Command

```bash
python NumberGuessing.py
```

> Note: This project uses only the standard library and does not require additional packages.
