# Debugging Python Code

This project contains small Python programs that were reviewed and corrected to make their output behave as expected. The exercises focus on identifying and fixing issues in common conditional and loop-based code.

## What This Project Shows

* How to run and test simple Python console programs.
* How to check numbers for even/odd results.
* How to generate FizzBuzz output for a numeric range.
* How to evaluate leap year rules using nested conditionals.
* How debugging small programs improves correctness and program flow.

## How to Run

### Prerequisites

* Python 3.8 or newer
* Visual Studio Code or another text editor (optional)

### Steps

1. Open the project folder in your editor.
2. Open a terminal in the `Day 13 - Debugging Code` folder.
3. Run the Python script you want to test.

### Run Command

To run the even/odd checker:

```bash
python OddOrEven.py
```

To run the FizzBuzz program:

```bash
python FizzBuzz.py
```

To run the leap year checker:

```bash
python LeapYear.py
```

### Dependencies

> Note: This project uses only the standard library and does not require additional packages.
