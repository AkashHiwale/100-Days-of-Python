# Turtle Race Bidding Game

This project creates an interactive turtle race where the user bets on which colored turtle will reach the finish line first. The program animates multiple turtles moving across the screen and displays the race result after the user places a bet.

## What This Project Shows

* Displays a graphical race using the Python `turtle` module.
* Accepts user input through a popup dialog for placing a bet.
* Moves multiple turtle objects randomly to simulate a race.
* Uses program flow and condition checks to determine and display the winner.

## How to Run

### Prerequisites

* No additional packages are required

## Concepts Learnt

* **Event Listener (`screen.exitonclick()`)** – Waits for a click event on the window before closing, demonstrating how user interaction can trigger program flow.
* **Screen Text Input (`Screen.textinput()`)** – Prompts the user with a dialog box so the user can place a bet before the race starts.
