# Higher Lower Game

Higher Lower Game is a console application where the player tries to guess which of two public profiles has more social media followers. The game continues until the player makes an incorrect choice, with the score increasing for each correct answer.

## What This Project Shows

- Reads profile data from a local module and displays two comparison options.
- Uses random selection to present new profile comparisons each round.
- Accepts user input and validates the choice between option A or B.
- Tracks the player score across repeated rounds.
- Clears the console between rounds to keep the game display updated.

## How to Run

### Prerequisites

* Python 3.8 or newer
* Visual Studio Code (optional)

### Steps

1. Clone the repository.
2. Open the `Day 11 - Day 20/Day 14 - Higher Lower Game` folder.
3. Open a terminal in the project folder.
4. Run the application.

### Run Command

```bash
python HigherLowerGame.py
```
