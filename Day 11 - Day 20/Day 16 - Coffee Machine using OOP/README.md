# Coffee Machine using OOP

This project simulates a simple console-based coffee machine that accepts drink orders, checks ingredient availability, and processes payments. Users can order espresso, latte, or cappuccino, request a resources report, or turn the machine off.

## What This Project Shows

* Accepts user input to choose drinks or request a report.
* Checks available ingredients before making a drink.
* Processes coin-based payments and returns change.
* Uses object-oriented classes to separate responsibilities.

## How to Run

### Prerequisites

* Python 3.8 or newer
* A terminal or command prompt

### Steps

1. Open the `Day 16 - Coffee Machine using OOP` folder.
2. Open a terminal in this folder.
3. Run the application.

### Run Command

```bash
python main.py
```

### Dependencies

> Note: This project uses only the standard library and does not require additional packages.

## Concepts Learnt

* **Classes and Objects** – Used to represent the coffee machine, menu, drinks, and payment processor.
* **Methods** – Encapsulate behavior for reporting resources, checking availability, and processing payments.
* **Encapsulation** – Each class manages its own state and actions for clearer program structure.
* **Object-oriented design** – Separates responsibilities into reusable components for the menu, coffee maker, and money handling.
