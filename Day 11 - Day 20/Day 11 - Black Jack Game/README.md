# Black Jack Game

A console card game where the player competes against a dealer to build a hand value close to 21 without busting.

## What This Project Shows

- Lets the player draw additional cards or stand during a round.
- Uses card scoring rules with special Ace handling for 11 or 1.
- Implements dealer behavior that draws cards until reaching at least 17.
- Compares final hand totals to determine the winner.
- Loads ASCII art from a local module for a game title display.

## How to Run

### Prerequisites

* Python 3.8 or newer
* Visual Studio Code (optional)

### Steps

1. Clone the repository.
2. Open the `Day 11 - Day 20/Day 11 - Black Jack Game` folder.
3. Open a terminal in the project folder.
4. Run the application.

### Run Command

```bash
python BlackJack.py
```

### Dependencies

> Note: This project uses only the standard library and does not require additional packages.
