# Secret Auction Program

A command-line auction application where users can enter bids anonymously, then see which bidder offered the highest amount.

## What This Project Shows

- Collecting multiple bids from different users.
- Storing bid information in a dictionary for easy lookup.
- Comparing values to determine the highest bidder.
- Using loops and conditionals to keep the auction running until it ends.

## How to Run

1. Install Python 3.8 or newer.
2. Clone this repository.
3. Open the folder in VS Code.
4. Open the terminal in `Day 01 - Day 10/Day 09 - Secret Auction Program`.
5. Run:

   `python SecretAuctionProgram.py` or `py -u SecretAuctionProgram.py`

6. If you see an error about a missing dependency, run:

   `pip install <dependency-name>` or `py -m pip install <dependency-name>`

> Note: This project uses only the Python standard library.

## Concepts Learnt

- Working with dictionaries to store user bids
- Using loops to accept repeated input
- Applying conditional logic to determine the winning bid
- Handling user interaction in a console program

## What I Learned

This project reinforces how to manage and evaluate multiple pieces of user input. It also demonstrates how simple data structures can drive basic decision-making logic in a program.
