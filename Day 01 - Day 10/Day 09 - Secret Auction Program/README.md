# Secret Auction Program

A command-line auction tool that collects anonymous bids and determines the highest bidder.

## What This Project Shows

- Accepts repeated user bids until the auction ends.
- Stores bidder names and bid amounts in a dictionary.
- Compares bids to find the highest value.
- Uses a function to separate winner selection logic from input collection.

## How to Run

### Prerequisites

* Python 3.8 or newer
* Visual Studio Code (optional)

### Steps

1. Clone the repository.
2. Open the `Day 01 - Day 10/Day 09 - Secret Auction Program` folder.
3. Open a terminal in the project folder.
4. Run the application.

### Run Command

```bash
python SecretAuctionProgram.py
```

### Dependencies

> Note: This project uses only the standard library and does not require additional packages.

## Concepts Learnt

- **Dictionaries** – Stores bidder names as keys and bid amounts as values.
- **Dictionary traversal** – Iterates through stored bids to find the highest bidder.
- **Function definition** – Encapsulates winner calculation in `find_winner()`.
